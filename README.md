# 🧮 Calculadora CLI

Uma calculadora de linha de comando simples, feita em Python, que realiza as quatro operações matemáticas básicas.

## ✨ Funcionalidades

- ➕ **Adição** — soma dois ou mais números
- ➖ **Subtração** — subtrai dois ou mais números da esquerda para a direita
- ✖️ **Multiplicação** — multiplica dois ou mais números
- ➗ **Divisão** — divide dois ou mais números da esquerda para a direita, com proteção contra divisão por zero

## 🚀 Como usar

**Pré-requisito:** Python 3 instalado na máquina.

```bash
python main.py
```

Ao executar, o programa irá:

1. Pedir que você escolha uma operação (`adição`, `subtração`, `multiplicação` ou `divisão`)
2. Solicitar os números desejados, separados por espaço
3. Exibir o resultado no terminal

### Exemplo

```
Bem-vindo à Calculadora CLI!
Escolha a operação (adição, subtração, multiplicação, divisão): adição
Digite os números para somar, separados por espaço: 10 20 30
60.0
```

> **Atenção para divisão:** números decimais devem usar ponto como separador (ex: `5.5`). Divisão por zero não é permitida.
